# Subject Guess v3

Запуск:

```powershell
py -m pip install -r requirements.txt
py server.py
```

Открой http://127.0.0.1:8000

## ADM1.geojson

Положи файл `ADM1.geojson` рядом с `server.py` в корень проекта. Фронтенд грузит `/adm1/RUS` и `/adm1/UKR`:

- основные субъекты берутся из `RUS`;
- Крым, Севастополь, Донецкая, Луганская, Херсонская и Запорожская области сначала ищутся в `UKR`, потом в `RUS`;
- если конкретный регион не найден по имени, используется fallback-прямоугольник.

Внизу/сверху интерфейса отображается строка вида `Контуры: ADM1 87/89; RUS: 81, UKR: 6; остальные — fallback`.
